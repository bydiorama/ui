# Directed cut — generation becomes a working brand workspace

Audience: a social-feed viewer who needs to recognize the product and its
value before inspecting implementation. The headline and brand assets carry
that meaning. The code window establishes generation, then hands attention
to the workspace. Existing approved Paper geometry, type, colors and assets
remain the visual vocabulary.

9.5-second loop, 1600 × 1200, 60fps. Separate artifact from both prior cuts.

| Beat | Intention |
| --- | --- |
| 0–1.2s | Shell, headline and blue brand surface overlap in a decisive opening. Identify the product early. |
| 1.2–2.5s | Supporting navigation and metrics complete. Dense 11px code stream accompanies construction. |
| 2.5–3.65s | Code keeps advancing. From 3.0s its widget fades continuously, overlapping the start of photo expansion. |
| 3.2–3.85s | Three library images expand into the approved Paper arrangement. Reveal the useful asset collection. |
| 4.1–5.05s | Views and storage update with their graphs, in order. Show a live workspace rather than decorative motion. |
| 5.35–5.95s | Invite press and member-count increase form one cause/effect pair. |
| 6–7.7s | Hold the complete product for recognition and recall. |
| 7.7–9.1s | Compact local retirement, corners return to square, contours resolve to the grid. |
| 9.1–9.5s | Match the opening grid for a clean loop. |

Restraint: no unmotivated search focus pulse, no camera drift, no global
shimmer, no matrix particles, no bouncy numbers. Motion uses the existing
smooth-out and ease-in-out curves; glyph changes travel 4px without overshoot.
Construction lines are quieter. All changes have a timing or hierarchy role.
